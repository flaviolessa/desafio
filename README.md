# Desafio dos Bagres

Jogo de navegador para uma pessoa contra o computador, com três dificuldades:

- Nível Difícil
- Nível Intermediário
- Nível Chan

## Executar no VS Code

Abra esta pasta no VS Code. Para testar, abra `index.html` no navegador ou use a extensão Live Server.

## Controles

- A/D ou setas: movimentar
- W ou seta para cima: pular
- F ou espaço: atacar
- G: golpe especial

## Publicar no GitHub Pages

Crie um repositório novo e separado, envie todo o conteúdo desta pasta e ative o GitHub Pages em Settings > Pages, publicando a branch `main` pela pasta raiz.
